## 2024-10-24 - Web UX Patterns Inapplicable to CLI Application
**Learning:** This repository contains a Python command-line utility for downloading Adobe Connect recordings, not a web application frontend. Standard web accessibility (ARIA, focus states) and UX patterns (CSS, HTML semantics) cannot be applied here.
**Action:** Halted UX enhancement PR creation as no suitable web-based micro-UX improvements can be identified. Future UX focus on this repo should be strictly CLI-based (e.g., TUI, argparse help clarity).
